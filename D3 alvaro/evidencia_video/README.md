# Evidencia de la grabación

Pendiente de ejecutar la demo real en Colab y grabar el video.

1. Ejecutar C1 del notebook y descargar `evidencia_video_…zip`.
2. Guardar aquí el ZIP. No sustituir las trazas históricas.
3. Añadir el enlace público del video y comprobar que los `run_id` seleccionados en `indice_video.json` coincidan con las consultas visibles.
4. Actualizar el manifiesto de auditoría al incorporar archivos.

El ZIP distingue nuevas inferencias y fallo H03 histórico. Los archivos temporales producidos por las pruebas simuladas no son evidencia del video.
